01 — Product

A narrow tool for a clear task

The application is used by its developer and a small private team. A user enters up to three match identifiers, selects the relevant team side, and starts the import after each game.

The current prototype reads completed match records through Riot's documented Match-V5 API. It writes match metadata and role-specific performance statistics into an existing team workbook without providing live assistance or influencing gameplay decisions.

02 — User flow

From completed match to review sheet

  1. 01

    Choose destination

    Select a local Excel workbook or a privately controlled Google Sheet.

  2. 02

    Provide match input

    Enter one to three completed match IDs and choose Blue or Red side.

  3. 03

    Retrieve authorized data

    The desktop app requests post-game records over HTTPS from documented Riot endpoints.

  4. 04

    Write structured rows

    Top, Jungle, Mid, Bottom and Support statistics are added for retrospective analysis.

03 — Data & privacy

Local credentials. Controlled destinations.

✓ The Riot API key is entered locally and is never embedded in the executable.

✓ Optional key storage uses Windows Data Protection API for the current Windows account.

✓ Google mode sends match data to the user's own Apps Script deployment; it does not transmit the Riot API key.

✓ This website uses no analytics, advertising, cookies, accounts or data-entry forms.

✓ The product does not sell data or operate as a data broker.

04 — Requested access

Consent-based Custom Game support

RSO

Explicit player authorization

The proposed RSO flow would let every participating user sign in with Riot and explicitly authorize access to their own Custom Game data. Client secrets would be stored on a secure backend, never in the distributed executable.

TOURNAMENT-V5

Reliable future scrims

Tournament Codes would be used for future organized team scrims so match identifiers and results can be collected through Riot's documented tournament workflow.

05 — Product boundaries

Not provided

Real-time information, scouting, public match histories, player shaming, reports, betting, advertising, MMR or ELO estimates.

Intended value

Private post-game reflection, team improvement and consistent record keeping using data participants are authorized to analyze.
