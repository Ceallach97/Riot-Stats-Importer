Privacy information · Last updated 18 September 2026

Privacy

Riot Stats Importer is a private, non-commercial Windows prototype for post-game League of Legends analysis. This website is informational and does not collect personal data.

Website data

This static website uses no accounts, forms, analytics, advertising, tracking pixels or application cookies. The hosting provider may process basic connection logs under its own policies.

Desktop application data

The desktop application processes match identifiers, selected team sides and post-game match records requested from documented Riot APIs. Results are written only to a workbook or private Google Sheet selected by the user.

API credentials

Riot API keys are entered locally and are not embedded in the executable. Optional local storage is protected by Windows Data Protection API for the current Windows account. In Google Sheets mode, the Riot API key is not sent to Google Apps Script.

Proposed RSO integration

If Riot Sign On is approved and implemented, users will be shown the requested access and must explicitly authorize it. RSO client secrets and refresh credentials will be held by a secure backend rather than distributed inside the Windows executable. This notice will be updated before that functionality becomes available.

Sharing and retention

The project operator does not sell match data, operate as a data broker or maintain a centralized analytics database. Workbook and Sheet retention is controlled by their respective owners.
